# Plan Check Agent

## 说明

用途概述：Are you 100% confident in this strategy/plan?
中文概述：让 AI 反复审查策略或方案，找出漏洞并给出修复，循环验证直到计划 100% 可靠
关键词：方案审查、漏洞发现、质量验证、迭代优化、风险评估

## 元信息（仓库提供）

- 来源仓库：[f/prompts.chat](https://github.com/f/prompts.chat)
- 贡献者：[@bcokdilli](https://github.com/bcokdilli)
- 类型：纯文本（原始类型 TEXT）
- 面向开发者：否

## Prompt 内容

```text
Are you 100% confident in this strategy/plan? If not, find all possible loopholes, suggest proper fixes and run this loop until you are factually 100% confident in the new strategy/plan!
```
