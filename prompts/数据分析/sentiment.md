# Sentiment Classification with LLMs

## 说明

用途概述：This prompt tests an LLM's text classification capabilities by prompting it to classify a piece of text.
中文概述：提示LLM将一段文本分类为 neutral/negative/positive 三种情绪。
关键词：情绪分类、sentiment、文本分类、情感分析

## 元信息（仓库提供）

- 来源仓库：[dair-ai/Prompt-Engineering-Guide](https://github.com/dair-ai/Prompt-Engineering-Guide)
- 贡献者：DAIR.AI
- 类型：纯文本（原始类型 TEXT）
- 面向开发者：否

## Prompt 内容

```
Classify the text into neutral, negative, or positive
Text: I think the food was okay.
Sentiment:
```
