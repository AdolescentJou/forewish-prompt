# Few-Shot Sentiment Classification with LLMs

## 说明

用途概述：This prompt tests an LLM's text classification capabilities by prompting it to classify a piece of text into the proper sentiment using few-shot examples.
中文概述：用few-shot示例提示LLM将文本分类为积极/消极情绪，测试LLM的文本分类能力。
关键词：few-shot、情绪分类、sentiment、文本分类、示例学习

## Prompt 内容

```markdown
This is awesome! // Negative
```
