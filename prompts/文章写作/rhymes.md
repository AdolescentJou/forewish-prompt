# Rhyming with Proofs

## 说明

用途概述：This prompt tests an LLM's natural language and creative capabilities by prompting it to write a proof of infinitude of primes in the form of a poem.
中文概述：要求以每一行都押韵的诗文体裁写出素数有无穷多个的证明，测试语言与创意能力。
关键词：数学证明、押韵诗、素数、创意测试

## 元信息（仓库提供）

- 类型：纯文本（原始类型 TEXT）
- 面向开发者：否

## Prompt 内容

```
Can you write a proof that there are infinitely many primes, with every line that rhymes?
```
