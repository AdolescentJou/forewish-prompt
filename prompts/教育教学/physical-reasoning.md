# Physical Reasoning with LLMs

## 说明

用途概述：This prompt tests an LLM's physical reasoning capabilities by prompting it to perform actions on a set of objects.
中文概述：让 LLM 对书本、鸡蛋等一组物体做物理推理，规划稳定堆叠方式。
关键词：physical reasoning、堆叠、物体操作、LLM 测试

