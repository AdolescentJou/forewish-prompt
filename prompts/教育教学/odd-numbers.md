# Adding Odd Numbers with LLMs

## 说明

用途概述：This prompt tests an LLM's mathematical capabilities by prompting it check if adding odd numbers add up to an even number. We will also leverage chain-of-thought prompting in this example.
中文概述：让 LLM 用 chain-of-thought 分步判断一组数中奇数相加是否得偶数，测试数学推理。
关键词：LLM、chain-of-thought、数学推理、odd numbers、even

## Prompt 内容

```markdown
The odd numbers in this group add up to an even number: 15, 32, 5, 13, 82, 7, 1. 
Solve by breaking the problem into steps. First, identify the odd numbers, add them, and indicate whether the result is odd or even. 
```
