# Any Programming Language to Python Converter

## 说明

用途概述：I want you to act as a any programming language to python code converter.
中文概述：让 AI 将任意编程语言代码转换为带注释、便于理解的 Python 代码
关键词：代码转换、Python、代码翻译、注释

