# Generate Code Snippets with LLMs

## 说明

用途概述：This prompt tests an LLM's code generation capabilities by prompting it to generate the corresponding code snippet given details about the program through a comment using `/* <instruction> */`.
中文概述：通过 /* 指令 */ 注释让 AI 生成相应代码片段，用于测试大模型的代码生成能力。
关键词：代码生成、注释指令、LLM 测试

## 元信息（仓库提供）

- 来源仓库：[dair-ai/Prompt-Engineering-Guide](https://github.com/dair-ai/Prompt-Engineering-Guide)
- 贡献者：DAIR.AI
- 类型：纯文本（原始类型 TEXT）
- 面向开发者：否

## Prompt 内容

```markdown
/*
Ask the user for their name and say "Hello"
*/
```
