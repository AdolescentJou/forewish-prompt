# Jailbreaking LLMs

## 说明

用途概述：This adversarial prompt example aims to demonstrate the concept of jailbreaking which deals with bypassing the safety policies and guardrails of an LLM. <Callout type="warning" emoji="⚠️"> Please note that the prompt example provided below is for raising awareness of the weakness of LLMs and for educational purposes alone. Also note that many LLM providers update their LLMs so many jailbreaking techniques might not be as effective as when they were initially discovered. </Callout>
中文概述：对抗性示例（仅教育用途）演示如何绕过 LLM 安全护栏，如请求写“如何偷车”主题的诗
关键词：prompt injection、LLM安全、adversarial、教育示例
