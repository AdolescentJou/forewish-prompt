# Step 2: Outline Creation

## 说明

用途概述：Based on the ideas generated in the previous step, create a detailed outline.
中文概述：AI 承接上一步生成的点子，产出含主次章节、关键要点、各节耗时估算与依赖关系的分层详细大纲。
关键词：大纲创建、内容规划、层级结构、写作流程

## 元信息（仓库提供）

- 来源仓库：[f/prompts.chat](https://github.com/f/prompts.chat)
- 贡献者：[@f](https://github.com/f)
- 类型：纯文本（原始类型 TEXT）
- 面向开发者：否

## Prompt 内容

```text
Based on the ideas generated in the previous step, create a detailed outline.

Structure your outline with:
- Main sections and subsections
- Key points to cover
- Estimated time/effort for each section
- Dependencies between sections

Format the outline in a clear, hierarchical structure.
```
