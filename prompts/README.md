# prompts —— 全部 prompt（共 2431 条，18 个分类）

整合自开源仓库 f/prompts.chat、dair-ai/Prompt-Engineering-Guide 与 danielmiessler/Fabric。

## 怎么用

- **直接问 AI**：用中文描述你想做的事，让它在本库中检索并把最相关的模板给你；
- 或命令行：`python3 tools/ask.py "你想干的事"`（关键词+向量语义混合检索，详见 ../USAGE.md）；
- 每个 prompt 文件头部都有一行 `中文概述` 与 `关键词`，打开即懂用途。
